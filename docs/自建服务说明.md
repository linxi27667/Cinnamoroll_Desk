# 自建服务简要

本客户端可对接开源 RustDesk 服务端组件：

- `hbbs`：信号 / ID
- `hbbr`：中继
- （可选）API / Web 管理

## 常用端口

- `21115` TCP（NAT 测试）
- `21116` TCP/UDP（信号）
- `21117` TCP（中继）
- `21118` / `21119` WebSocket

## ALWAYS_USE_RELAY

- `Y`：强制所有会话走中继（好连，但难直连）
- `N`：允许打洞直连，失败再回落中继（更流畅的前提）

手机端在「开源服务 + API + Key」场景下，通常仍需开启 WebSocket，与是否强制中继不是同一件事。

## 安全

请将真实 IP、Key、账号密码放在私密配置或密码管理器中，不要写进公开文档。
