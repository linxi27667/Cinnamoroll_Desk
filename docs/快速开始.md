# 客户端快速开始

## Windows

1. 下载 `Cinnamoroll-Windows-portable.zip`
2. 解压到任意目录（避免过深中文路径亦可）
3. 右键 `一键安装.bat` → 以管理员身份运行
4. 打开软件 → 设置 → 网络，填写自建 ID/中继、API、Key

静默安装命令（管理员）：

```bat
rustdesk.exe --silent-install
```

## Android

1. 下载 `Cinnamoroll-1.5.0-arm64.apk`
2. 安装后打开网络设置，填写同一套服务器
3. 开启「使用 WebSocket」
4. 登录或直接输入对方 ID 连接

## 连接质量

| 场景 | 建议 |
|------|------|
| 公网中继 | Bitrate 100%~300%，FPS 30 |
| 已打洞直连 | 可尝试 FPS 45~60 |
| 网页端 | 仅应急，固定走 WSS，不适合冲高清 |
