# 客户端快速开始

## Windows

1. 下载 `Cinnamoroll-Windows-portable.zip`
2. 解压
3. **优先双击 `install.bat`**（英文脚本，兼容性最好）
4. 若存在 `一键安装.bat`，也可右键以管理员运行
5. 打开软件后填写自建服务器（ID/中继、API、Key）

管理员手动安装：

```bat
rustdesk.exe --silent-install
```

## Android

1. 安装 `Cinnamoroll-1.5.0-arm64.apk`
2. 开启「使用 WebSocket」
3. 填写同一套服务器配置
